# Health Plus

Health Plus is a simple React web app for online healthcare services.

## Features

- Book appointments with doctors
- Get online medical consultation
- Responsive design for mobile and desktop

## Tech Stack

- React
- React Router DOM
- React Toastify
- Font Awesome

## Run Locally

App URL: `http://localhost:3000/Health-Plus`
